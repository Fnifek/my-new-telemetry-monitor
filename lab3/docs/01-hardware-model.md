# Аппаратная модель: тракт и расчёты

## 1. Почему модель

В задании ЛР3 допускаются аппаратный аналоговый датчик, аппаратный цифровой датчик,
математическая модель и внешнее API. В ЛР2 уже была выбрана математическая модель
теплового процесса, поэтому ЛР3 сохраняет вариант «модель», но поднимает уровень:
моделируется не только температура, а весь измерительный тракт с электрическими
величинами, кодом АЦП, таймингом и протоколом.

## 2. NTC и делитель

Терморезистор 10 кОм, B3950:

```
R(T) = R25 * exp(B * (1/T - 1/T25))
V(T) = Vs * R(T) / (Rtop + R(T))
```

- `R25 = 10 кОм`, `B = 3950 К`;
- `Rtop = 10 кОм`, `Vs = 3,3 В`;
- при 25 °C `V = 1,65 В`, при 90 °C `V ≈ 0,28 В`, при 110 °C `V ≈ 0,17 В`.

Обратное преобразование:

```
R = Rtop * V / (Vs - V)
T = 1 / (1/T25 + ln(R/R25)/B) - 273,15
```

Класс `NtcChannel` хранит эти формулы; `temperature()` — обратная функция.

## 3. ADS1115

- 16 бит, PGA ±4,096 В;
- LSB = 4,096 / 65536 = 62,5 мкВ;
- 860 SPS, три канала по кругу → до 286,7 Гц на канал;
- таймер ESP32 выбирает последнее преобразование каждые 10 мс.

Шаг квантования в градусах зависит от крутизны `dV/dT`:

```
dV/dT = Vs * Rtop / (Rtop + R)^2 * (-B * R / T^2)
```

| T, °C | dV/dT, В/К | LSB, °C |
|---|---|---|
| 25 | 0,0367 | 0,0017 |
| 90 | 0,0077 | 0,0081 |
| 110 | 0,0042 | 0,0147 |

Модель `Ads1115Model` добавляет ±1 МЗР синусоидальной нелинейности и 8 мкВ шума.

## 4. Аналоговый фильтр

Второй порядок, Саллен–Кей, `fc = 30 Гц`:

- ослабление на 49,5 Гц — 9,25 дБ;
- групповая задержка на низких частотах — 7,5 мс;
- предотвращает наложение спектров на входе АЦП.

## 5. Тахометрия

4-контактные вентиляторы дают 2 импульса на оборот:

```
n = 60 / (z * T), z = 2
Δn = 60 * ΔT / (z * T^2) = n^2 * z * ΔT / 60
```

При 1 мкс и 3000 об/мин: 0,3 об/мин; при 6000: 1,2 об/мин. Модель добавляет
джиттер 2 мкс, усредняет 4 периода и по таймауту 500 мс выдаёт 0.

## 6. Тепловой процесс

`ThermalPlant` повторяет ЛР2:

```
T[k+1] = T[k] + (T_target - T[k]) * (1 - exp(-dt/tau))
```

- `tau = 8 с`;
- `T_target` = 45 °C / 82 °C, период 90 с;
- ripple 0,35 °C на 0,12 Гц;
- шум 0,35 °C;
- наводка 0,7 °C на 49,5 Гц.

`BoardModel` переводит температуру в напряжение, квантует его ADS1115, обратно
считает температуру, измеряет тахометр и INA219 и заполняет `TelemetryFrame`.

## 7. Тайминг

- источник/тепловая модель — 200 Гц;
- кадр — 100 Гц;
- ADS1115 — до 286,7 Гц на канал;
- тахометр — capture 1 мкс, обновление 100 Гц;
- INA219 — 10 Гц;
- PWM — 25 кГц.

Возраст отсчёта ADS1115 в кадре — 0…3,5 мс. Это учитывается в бюджете задержки.

## 8. Классы

| Класс | Ответственность |
|---|---|
| `NtcChannel` | сопротивление, напряжение, обратное преобразование |
| `Ads1115Model` | квантование, INL, шум |
| `TachometerModel` | период, джиттер, усреднение |
| `ThermalPlant` | тепловая инерция |
| `BoardModel` | сборка `BoardSample` и `TelemetryFrame` |
| `Aead` | AES-256-GCM через BCrypt |
| `encode_frame` / `decode_frame` | конверт 60 байт |

## 9. Что не моделируется

Самонагрев NTC, долговременный дрейф, старение конденсаторов, ЭМП импульсного
питания, тепловые градиенты корпуса, реальные потери UART/Wi-Fi. Для учебной
модели эти эффекты второстепенны; для опытной эксплуатации их нужно добавить.
