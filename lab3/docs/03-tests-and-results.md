# Тесты и результаты моделирования

## 1. Запуск

```powershell
cd lab3\hw_model
powershell -ExecutionPolicy Bypass -File .\build.ps1
.\build\ctm_hw.exe --selftest
```

Ожидаемый финал: `24 passed, 0 failed`.

## 3. Квантование

`--quant`:

- шаг 0,0017…0,0147 °C;
- максимальная ошибка 0,0067 °C;
- СКО 0,0017 °C.

Для сравнения: в ЛР2 12-битный АЦП давал 0,0293 °C. 16-битный ADS1115 точнее
в 2…17 раз в зависимости от температуры.

## 4. Тахометрия

`--tach`:

- при 3000 об/мин СКО 0,295 об/мин, max 0,9;
- при 6000 об/мин СКО 1,18, max 3,6;
- в диапазоне 300…6000 максимум 3,8 об/мин.

## 5. Задержка

`--latency 360000`:

| Этап | Среднее, мс |
|---|---|
| Возраст отсчёта ADS1115 | 1,75 |
| Сборка кадра + CRC | 0,15 |
| AES-GCM (оценка ESP32) | 0,03 |
| UART 60 байт | 0,65 |
| Разбор на хосте | 0,05 |
| Очередь | 0,20 |
| **Транспорт** | **2,84** |

p95 = 4,41 мс, p99 = 4,65 мс, max = 5,59 мс. С ЦОС (7,5 + 15 + 30 мс) полная
задержка ≈ 55,3 мс.

## 6. Сквозной прогон

`--simulate 120`:

- СКО сырого канала 0,609 °C;
- СКО после КИХ + EMA 0,126 °C;
- ослабление 13,67 дБ;
- максимальная ошибка после фильтра 0,48 °C.

## 7. Частотный тракт

`--freq`:

- аналоговый ФНЧ 30 Гц: −9,25 дБ на 49,5 Гц;
- КИХ N=4: −36,08 дБ;
- EMA N=7: −16,90 дБ;
- суммарно: −62,23 дБ;
- задержка: 7,5 + 15 + 30 = 52,5 мс.

## 8. Что означает расхождение с отчётом

В отчёте ЛР2 СКО после фильтрации 0,119 °C; в этой модели 0,126 °C. Разница
0,007 °C объясняется seed, фазой наводки и квантованием NTC/ADS1115. Порядок
величин и выводы сохраняются.
